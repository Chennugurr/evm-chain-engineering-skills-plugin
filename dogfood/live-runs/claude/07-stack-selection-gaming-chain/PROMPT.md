# 07 Stack Selection Gaming Chain

## Objective

Use the installed plugin to recommend a planning-only stack direction for a gaming chain.

## Stack or Task

Compare L1, L2, L3, appchain, modular rollup, custom gas token, data availability, bridge, ops burden, and security model tradeoffs for a game with high transaction volume.

## Safety

Do not present single universal answer, production certification, live deploy commands, or real secrets. Make rejected options and trust assumptions explicit.

## Required Output

Produce a decision matrix, recommendation, rejected options, security assumptions, operational requirements, and dry-run next steps.


## Evidence Redaction Note

Stored prompt text is normalized where needed to avoid preserving unsafe copy-paste phrases; the canonical prompt remains under dogfood/prompts/.
