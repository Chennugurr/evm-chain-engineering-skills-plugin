# 04 ZKsync ZK Stack Chain

## Objective

Use the installed plugin to design a planning-only ZKsync ZK Stack chain package.

## Stack or Task

Plan a ZK Stack chain with prover capacity, proof latency, sequencer operations, bridge assumptions, L1 contracts, monitoring, and rollup or validium tradeoffs.

## Safety

No real secrets, deploys, approval markers, or mainnet actions. Keep commands dry-run only and clearly mark version-sensitive commands as needing current upstream verification.

## Required Output

Produce an artifact bundle or equivalent structured answer with ADR, chain spec, infrastructure plan, security review, launch gates, selected skills, and validation notes.
