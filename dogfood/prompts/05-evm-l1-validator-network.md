# 05 EVM L1 Validator Network

## Objective

Use the installed plugin to design a safe EVM L1 validator-network testnet package.

## Stack or Task

Plan a PoSA-style EVM L1 testnet with validator set design, validator economics, genesis, bootnodes, RPC, explorer, governance, native token, chain ID checks, and launch gates.

## Safety

Do not create validator keys, publish key material, deploy live infrastructure, or claim production safety. Require signer separation, dry-run validation, and human security review.

## Required Output

Produce an artifact bundle or equivalent structured answer with ADR, chain spec, infrastructure plan, security review, launch gates, selected skills, and validation notes.
