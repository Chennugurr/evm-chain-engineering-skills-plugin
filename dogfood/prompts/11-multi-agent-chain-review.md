# 11 Multi-Agent Chain Review

## Objective

Use the installed plugin to coordinate an independent review of an OP Stack public testnet plan.

## Stack or Task

Ask for chain architecture, infrastructure operations, protocol security, docs freshness, and release readiness viewpoints. If subagents are available, use them and capture evidence. If not, say they are unavailable.

## Safety

Do not fake subagent use. Do not create secrets, deploy, broadcast, or claim production safety without audit, dry-run validation, and approval.

## Required Output

Return independent findings, severity, deduplicated risks, handoff notes, and whether subagent evidence was actually observed.
