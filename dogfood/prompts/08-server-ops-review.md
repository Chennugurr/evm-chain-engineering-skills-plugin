# 08 Server Ops Review

## Objective

Use the installed plugin to review a blockchain server operations plan for safety and completeness.

## Stack or Task

Review sequencer, batcher, proposer, RPC, archive, explorer, bridge backend, monitoring, alerting, backups, firewalling, rate limits, signer separation, and incident response.

## Safety

Do not expose public admin/debug RPC, use unpinned images, create real secrets, or approve production launch without dry-run validation.

## Required Output

Return findings with severity, remediation, missing controls, validation commands, and a security review handoff.
