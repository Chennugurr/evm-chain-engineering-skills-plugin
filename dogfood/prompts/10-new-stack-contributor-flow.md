# 10 New Stack Contributor Flow

## Objective

Use the installed plugin to explain how a contributor should add support for a new chain stack safely.

## Stack or Task

Cover stack profile creation, upstream sources, skill or reference updates, behavior evals, artifact fixtures, generated config validation, security assumptions, launch gates, tests, and docs.

## Safety

Do not claim support is complete without fixtures and validation. Do not require private docs or secret material, and keep command examples dry-run or local validation only.

## Required Output

Produce a contributor checklist, files to update, validation commands, and release evidence requirements.
