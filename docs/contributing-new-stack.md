# Contributing a New Stack

A new stack contribution must add a stack profile, source refs in `docs/upstream-sources.md`, skill trigger updates or an existing skill mapping, security assumptions, stack-specific roles, artifact fixture coverage if major, acceptance coverage if workflow-supported, generated config validator updates for new config types, behavior eval coverage, launch gates, and passing secret/profile/artifact validation.

Use `templates/new-stack-profile.yaml`, `templates/new-stack-skill/SKILL.md`, and `templates/new-stack-reference.md` as starting points.
