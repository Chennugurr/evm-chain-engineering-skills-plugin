# v0.3.0-beta Release Plan

v0.3.0-beta is a live agent QA milestone. The harness can be validated offline, but the release tag must wait until strict live evidence exists.

Bootstrap acceptance:

- `make validate-v03-bootstrap` passes.
- Release readiness is false.
- Codex and Claude transcript counts may be pending.
- Hook observations may be pending.

Strict release acceptance:

- `make validate-v03` passes.
- At least six required prompts are captured for Codex.
- At least six required prompts are captured for Claude.
- Hook activation is observed or documented as a platform limitation with evidence.
- Skill routing scorecard is produced from live evidence.
- Generated artifact bundles validate.
- Secret scans and known-bad checks pass.

Do not create `v0.3.0-beta` until strict release acceptance passes.
